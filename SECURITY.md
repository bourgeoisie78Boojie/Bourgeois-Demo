# Security policy

Please do not open public issues containing vulnerabilities, credentials, personal data, or exploit details.

Report security concerns privately using GitHub's **Report a vulnerability** feature if enabled, or contact BourgeoisAI through https://www.bourgeoisai.com/consulting.

Scope: this public demonstration repository and its website. The private production inference service is maintained separately. Never submit PHI, access tokens, passwords or other sensitive data to the public demo.

No guarantee of a response time or bug bounty is offered. If you discover a credential, do not use it; report it privately so it can be revoked and rotated.
